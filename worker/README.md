# MechaGen Python Worker

The `cadquery_worker.py` script is an isolated Python process that builds CAD solids from CadQuery source code generated by the deterministic JS translator.

## How it works

1. Node.js `solidBuildService.js` spawns this script as a child process
2. A JSON job is piped to stdin
3. The worker builds the solid using CadQuery, exports an STL, runs mesh checks
4. A structured JSON result is written to stdout
5. Exit code 0 = success, 1 = failure

## Setup

```bash
# From the mechagen root
cd worker
python3 -m venv .venv
source .venv/bin/activate
pip install cadquery trimesh
```

## Environment Variables

| Variable | Default | Purpose |
|---|---|---|
| `CADQUERY_PYTHON` | `python3` | Exact Python executable to use |
| `CADQUERY_VENV` | — | virtualenv root (activates automatically) |
| `CADQUERY_TIMEOUT_MS` | `60000` | Worker timeout in ms |

## Pointing the backend at your venv

```bash
# Option A: set the executable directly
export CADQUERY_PYTHON=/path/to/worker/.venv/bin/python3

# Option B: set the venv root (backend will activate it automatically)
export CADQUERY_VENV=/path/to/worker/.venv
```

## Stdin contract

```json
{
  "jobId":      "string",
  "source":     "python source code (generated by cadqueryTranslator.js)",
  "outputPath": "/absolute/path/to/output.stl",
  "timeout":    60000
}
```

## Stdout contract

```json
{
  "jobId":         "string",
  "success":       true,
  "stlPath":       "/absolute/path/to/output.stl",
  "stlSizeBytes":  12345,
  "executionMs":   3200,
  "stdout":        "",
  "stderr":        "",
  "error":         null,
  "meshCheck":     { "triangleCount": 144, "valid": true }
}
```

## Security

- CadQuery source is **never generated directly by the LLM**
- Source is produced by the deterministic `cadqueryTranslator.js` from a validated geometry plan
- The `exec()` call uses a **restricted builtins namespace** — only math-safe operations are available
- No file system, network, or subprocess access inside the executed source
- Worker runs with a configurable timeout and is killed if it exceeds it
